# 真实流水排名助手

面向 Windows 10/11 的完全离线桌面工具：从长截图识别用户名与电池流水，记录舰长、提督、总督上船明细，扣除后自动重新排名，并支持批量复制用户名与导出 Excel。

默认发布版本使用 Neutralinojs + Windows WebView2，属于本地桌面客户端，不是在线网页。界面、图片和流水数据均在本机处理。

请使用 v1.1.1 或更高版本；v1.1.0 的发布包存在本地页面路径错误，会显示无法打开 `127.0.0.1` 页面。

## 使用规则

- 截图识别只保留原始流水不低于 10,000 的用户。
- 多张截图出现同名用户时，保留最高原始流水。
- 上船扣除电池 = 人民币价格 × 数量 × 10。
- 最终流水 = 原始流水 − 全部上船扣除电池，允许为负数。
- 批量复制只复制最终流水不低于 10,000 的用户名，按最终排名一行一个。
- 每次启动为空数据，不保存上一轮内容。

## 开发运行

```bash
npm install
npm start
```

运行测试：

```bash
npm test
```

打包轻量 Windows 10/11 64 位版本：

```bash
npm run build:light
```

如需构建旧版 Electron 客户端：

```bash
npm run package:win
```

OCR 使用随程序附带的 PP-OCRv5 离线模型，运行时不需要联网。`npm install` 会自动生成浏览器端 OCR 文件。
